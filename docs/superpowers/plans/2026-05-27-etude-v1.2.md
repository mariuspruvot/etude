# Étude v1.2 Implementation Plan — Localized agents + closing the §14 gaps

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Localize the two sub-agents' prose to the learner's language, give `assess` the missing language footer, and resolve the two v1.1 §14 open questions (auto-promotion threshold + deep-dive spaced revision) — without touching the curriculum schema, the lint, or the integrity hook.

**Architecture:** Pure instruction edits to existing Markdown skills/agents, plus **one** new executable artifact: a typed pytest module that asserts both agents carry the language rule (the workflow requires a test when a localized agent is edited). Agents become self-localizing by reading `progress/profile.md` for the `language` field (they already have the `Read` tool). No new state file, no schema change. Spec: `docs/specs/2026-05-27-etude-v1.2-design.md`.

**Tech Stack:** Markdown + YAML frontmatter; existing `python3`/`uv`/`pytest`/`ruff`/`mypy` tooling (unchanged); the new test is plain stdlib `pathlib` + `pytest` (no new deps).

**Invariants (do NOT violate):**
- Never edit the repo `tracks/<t>/curriculum.md` schema or relax the lint.
- The integrity hook is unchanged: no skill/agent writes under `progress/*/exercises/*` except `prompt.md`/`feedback.md`. The `grader` keeps "do not modify files".
- Code/identifiers/CLI/concept-tags stay English; only prose is localized.
- Personal concepts keep the `personal:` prefix and stay track-local.

**Canonical strings (use verbatim where referenced):**
- LANGUAGE_FOOTER: `**Language:** write prose in the learner's \`progress/profile.md\` \`language\`; keep code, identifiers, CLI, and concept tags in English.`
- AGENT_LANG_PREAMBLE (grader): `Before grading, read \`progress/profile.md\` and note the \`language\` field (default \`en\` if absent or missing). Localize your prose to it — see the Language note at the end.`
- AGENT_LANG_PREAMBLE (interviewer): `Before starting, read \`progress/profile.md\` and note the \`language\` field (default \`en\` if absent or missing). Conduct the whole interview — questions, follow-ups, debrief — in that language. See the Language note at the end.`

- [ ] **Step 1: Write the failing test**

```python
"""Guard: both sub-agents must instruct localization of their prose.

The workflow requires a test whenever a localized agent is edited. Agents read
`progress/profile.md` for the learner's `language` and localize prose; code,
identifiers, CLI, and concept tags stay English.
"""

from pathlib import Path

AGENTS_DIR = Path(__file__).resolve().parent.parent / ".claude" / "agents"
LOCALIZED_AGENTS = ("grader.md", "interviewer.md")


def _agent_text(name: str) -> str:
    return (AGENTS_DIR / name).read_text(encoding="utf-8")


def test_localized_agents_exist() -> None:
    for name in LOCALIZED_AGENTS:
        assert (AGENTS_DIR / name).is_file(), f"missing agent: {name}"


def test_agents_read_profile_language() -> None:
    for name in LOCALIZED_AGENTS:
        text = _agent_text(name)
        assert "progress/profile.md" in text, f"{name} must read progress/profile.md"
        assert "language" in text, f"{name} must reference the language field"


def test_agents_carry_language_footer() -> None:
    needle = "**Language:**"
    for name in LOCALIZED_AGENTS:
        assert needle in _agent_text(name), f"{name} must carry the Language footer"
```

Run: `uv run --with pytest pytest tools/test_agents_language.py -v`
Expected: `test_agents_read_profile_language` and `test_agents_carry_language_footer` FAIL (current agents have no `profile.md` read and no `**Language:**` footer); `test_localized_agents_exist` passes.
